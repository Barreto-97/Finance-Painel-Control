Carregar base de dados

Anexe a planilha de Aging (aba Details) para gerar o painel. A base de líderes (Gestor / Supervisor / Gerente) já está embutida no código. Opcionalmente, carregue uma base de comentários já preenchida para restaurar Ação e Responsável.

Obrigatório

Base de Aging (Details)

Arquivo .xlsx contendo a aba Details, com cabeçalho iniciando em A5. Serão aplicados os filtros: Company Code contém I944, Debit/Credit Ind. = S/H, Shipment iniciando com B.

Opcional

Base de Comentários

Planilha com colunas Cliente, Value, Ação, Responsável — mesmo layout exportado pelo painel. O cruzamento é feito pela coluna Cliente.

⭳ Baixar modelo em branco
Regras aplicadas automaticamente: Company Code contendo "I944" · Debit/Credit Ind. igual a "S" ou "H" · Shipment iniciando com "B" · Gestor/Supervisor/Gerente atribuídos via base de líderes embutida (chave: Account) · Aging e Status calculados com base na data de hoje, do navegador, comparada à Net Due Date.
